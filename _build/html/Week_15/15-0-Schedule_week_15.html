Week 15: Repaso Final — Final Review Session#

Course: Models of Statistical Analysis (MAE)
Institution: Universidad de los Andes
Instructor: Prof. Alejandra Tabares
Week: 15

Objective#

Consolidate all major topics covered during the semester in preparation for the final exam. This review session synthesizes key models, assumptions, interpretation, and diagnostics into a unified reference. Emphasis is placed on:

  • Recognizing which model applies to a given problem

  • Stating and verifying model assumptions

  • Interpreting coefficients correctly

  • Choosing among competing models using formal criteria

Topics Covered This Week#

Topic 1 — Simple Linear Regression (SLR) — 15-1-Repaso_regresion_lineal.ipynb#

Concept

Key formula / idea

SLR model

\(Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i\), \(\varepsilon_i \sim \mathcal{N}(0, \sigma^2)\)

LINE assumptions

Linearity, Independence, Normality, Equal variance

OLS estimators

\(\hat{\beta}_1 = S_{xy}/S_{xx}\), \(\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}\)

Coefficient of determination

\(R^2 = SS_R / SS_T = 1 - SS_E/SS_T\)

Topic 2 — Multiple Linear Regression (MLR) — 15-1-Repaso_regresion_lineal.ipynb#

Concept

Key formula / idea

MLR model

\(\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\)

OLS estimators

\(\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}\)

Individual t-test

\(t = \hat{\beta}_j / \text{SE}(\hat{\beta}_j)\)

Global F-test

\(F = (SS_R/p) / (SS_E/(n-p-1))\)

Adjusted \(R^2\)

\(\bar{R}^2 = 1 - (1-R^2)\cdot(n-1)/(n-p-1)\)

Variance Inflation Factor

\(\text{VIF}_j = 1/(1 - R_j^2)\); VIF > 10 indicates multicollinearity

Topic 3 — Logistic Regression — 15-2-Repaso_regresion_logistica.ipynb#

Concept

Key formula / idea

Logit link

\(\ln\!\left(\frac{\pi}{1-\pi}\right) = \mathbf{x}^\top\boldsymbol{\beta}\)

Probability

\(\hat{\pi} = 1/(1+e^{-\mathbf{x}^\top\hat{\boldsymbol{\beta}}})\)

Odds ratio

\(\text{OR}_j = e^{\hat{\beta}_j}\) for one-unit increase in \(x_j\)

Estimation

Maximum likelihood (no closed form)

Model fit

Deviance, Hosmer-Lemeshow test, AUC/ROC

Topic 4 — Poisson Regression and GLMs — 15-2-Repaso_regresion_logistica.ipynb#

Concept

Key formula / idea

Poisson model

\(\ln(\mu_i) = \mathbf{x}_i^\top\boldsymbol{\beta}\); \(Y_i \sim \text{Poisson}(\mu_i)\)

Rate ratio

\(\text{RR}_j = e^{\hat{\beta}_j}\)

Overdispersion

\(\text{Var}(Y) \gg \mu\) → use Negative Binomial or quasi-Poisson

GLM framework

Exponential family + link function + linear predictor

Key Formulas Quick Reference#

Confidence and Prediction Intervals (SLR)#

\[ \text{CI for } E[Y|x^*]: \quad \hat{y}^* \pm t_{\alpha/2,\,n-2} \cdot \hat{\sigma}\sqrt{\frac{1}{n} + \frac{(x^* - \bar{x})^2}{S_{xx}}} \]
\[ \text{PI for } Y^*: \quad \hat{y}^* \pm t_{\alpha/2,\,n-2} \cdot \hat{\sigma}\sqrt{1 + \frac{1}{n} + \frac{(x^* - \bar{x})^2}{S_{xx}}} \]

Information Criteria#

\[ \text{AIC} = -2\ell(\hat{\boldsymbol{\beta}}) + 2p \qquad \text{BIC} = -2\ell(\hat{\boldsymbol{\beta}}) + p\ln(n) \]

Lower is better. BIC penalizes complexity more heavily for large \(n\).

Study Guide — Checklist by Topic#

Use this checklist when preparing for the exam. Mark each item when you feel confident.

Linear Regression#

  • Write the SLR and MLR models with all assumptions stated

  • Derive or explain OLS estimators conceptually

  • Interpret \(\hat{\beta}_j\) in both SLR and MLR

  • Conduct and interpret t-test and F-test from ANOVA table

  • Construct CI for \(\beta_j\), CI for \(E[Y|\mathbf{x}^*]\), PI for \(Y^*\)

  • Identify violations of LINE assumptions from residual plots

  • Calculate and interpret VIF

Model Diagnostics and Selection#

  • Interpret residuals vs fitted, QQ-plot, scale-location, leverage plots

  • Identify outliers vs high-leverage vs influential points

  • Compare models using AIC, BIC, adjusted \(R^2\)

  • Explain the bias-variance tradeoff for Ridge vs Lasso

Logistic Regression#

  • Derive the logistic regression probability formula from the logit link

  • Interpret log-odds, odds ratios, and probabilities

  • Evaluate model with confusion matrix: accuracy, sensitivity, specificity

  • Interpret ROC curve and AUC

Poisson Regression and GLMs#

  • State conditions for Poisson regression

  • Interpret rate ratios (exponentiated coefficients)

  • Diagnose overdispersion: residual deviance / df \(\gg 1\)

  • Identify the three GLM components for any given family

Survival Analysis (Week 14)#

  • Define \(S(t)\), \(h(t)\), \(H(t)\) and state their relationships

  • Explain right censoring and why it cannot be ignored

  • Compute a simple Kaplan-Meier estimate by hand for a small example

  • Interpret Cox PH coefficients as hazard ratios

  • State the proportional hazards assumption and describe how to check it

Exam Preparation Advice#

General recommendations:

  1. Work through the diagnostic checklist above before the review session so you can target remaining gaps.

  2. Practice interpreting model output (coefficient tables, ANOVA tables, confusion matrices) without running code — the exam may include printed outputs.

  3. Pay special attention to interpretation of coefficients: the answer always depends on the link function and the scale of the covariates.

  4. Review the assumptions for each model and know at least one diagnostic tool to check each assumption.

  5. For the GLM section, being able to identify the correct family and link function from a problem description is essential.
