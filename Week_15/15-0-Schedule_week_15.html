Semana 15: Repaso Final — Sesión de Revisión Final#

Curso: Modelos de Análisis Estadístico (MAE)
Institución: Universidad de los Andes
Docente: Prof. Alejandra Tabares
Semana: 15

Objetivo#

Consolidar todos los temas principales cubiertos durante el semestre en preparación para el examen final. Esta sesión de repaso sintetiza los modelos clave, supuestos, interpretación y diagnósticos en una referencia unificada. El énfasis se coloca en:

  • Reconocer qué modelo aplica a un problema dado

  • Enunciar y verificar los supuestos del modelo

  • Interpretar los coeficientes correctamente

  • Elegir entre modelos en competencia usando criterios formales

Temas de Esta Semana#

Tema 1 — Regresión Lineal Simple (RLS) — 15-1-Repaso_regresion_lineal.ipynb#

Concepto

Fórmula / idea clave

Modelo RLS

\(Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i\), \(\varepsilon_i \sim \mathcal{N}(0, \sigma^2)\)

Supuestos LINE

Linealidad, Independencia, Normalidad, Equivarianza

Estimadores MCO

\(\hat{\beta}_1 = S_{xy}/S_{xx}\), \(\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}\)

Coeficiente de determinación

\(R^2 = SS_R / SS_T = 1 - SS_E/SS_T\)

Tema 2 — Regresión Lineal Múltiple (RLM) — 15-1-Repaso_regresion_lineal.ipynb#

Concepto

Fórmula / idea clave

Modelo RLM

\(\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\)

Estimadores MCO

\(\hat{\boldsymbol{\beta}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}\)

Prueba t individual

\(t = \hat{\beta}_j / \text{SE}(\hat{\beta}_j)\)

Prueba F global

\(F = (SS_R/p) / (SS_E/(n-p-1))\)

\(R^2\) ajustado

\(\bar{R}^2 = 1 - (1-R^2)\cdot(n-1)/(n-p-1)\)

Factor de Inflación de la Varianza

\(\text{VIF}_j = 1/(1 - R_j^2)\); VIF > 10 indica multicolinealidad

Tema 3 — Regresión Logística — 15-2-Repaso_regresion_logistica.ipynb#

Concepto

Fórmula / idea clave

Enlace logit

\(\ln\!\left(\frac{\pi}{1-\pi}\right) = \mathbf{x}^\top\boldsymbol{\beta}\)

Probabilidad

\(\hat{\pi} = 1/(1+e^{-\mathbf{x}^\top\hat{\boldsymbol{\beta}}})\)

Razón de momios

\(\text{OR}_j = e^{\hat{\beta}_j}\) por un aumento de una unidad en \(x_j\)

Estimación

Máxima verosimilitud (sin forma cerrada)

Ajuste del modelo

Devianza, prueba de Hosmer-Lemeshow, AUC/ROC

Tema 4 — Regresión de Poisson y GLMs — 15-2-Repaso_regresion_logistica.ipynb#

Concepto

Fórmula / idea clave

Modelo Poisson

\(\ln(\mu_i) = \mathbf{x}_i^\top\boldsymbol{\beta}\); \(Y_i \sim \text{Poisson}(\mu_i)\)

Razón de tasas

\(\text{RR}_j = e^{\hat{\beta}_j}\)

Sobredispersión

\(\text{Var}(Y) \gg \mu\) → usar Binomial Negativa o quasi-Poisson

Marco GLM

Familia exponencial + función de enlace + predictor lineal

Referencia Rápida de Fórmulas Clave#

Intervalos de Confianza y de Predicción (RLS)#

\[ \text{IC para } E[Y|x^*]: \quad \hat{y}^* \pm t_{\alpha/2,\,n-2} \cdot \hat{\sigma}\sqrt{\frac{1}{n} + \frac{(x^* - \bar{x})^2}{S_{xx}}} \]
\[ \text{IP para } Y^*: \quad \hat{y}^* \pm t_{\alpha/2,\,n-2} \cdot \hat{\sigma}\sqrt{1 + \frac{1}{n} + \frac{(x^* - \bar{x})^2}{S_{xx}}} \]

Criterios de Información#

\[ \text{AIC} = -2\ell(\hat{\boldsymbol{\beta}}) + 2p \qquad \text{BIC} = -2\ell(\hat{\boldsymbol{\beta}}) + p\ln(n) \]

Un valor menor es mejor. El BIC penaliza la complejidad con más fuerza para \(n\) grande.

Guía de Estudio — Lista de Verificación por Tema#

Use esta lista de verificación al prepararse para el examen. Marque cada ítem cuando se sienta seguro.

Regresión Lineal#

  • [ ] Escribir los modelos RLS y RLM con todos los supuestos enunciados

  • [ ] Derivar o explicar conceptualmente los estimadores MCO

  • [ ] Interpretar \(\hat{\beta}_j\) en RLS y RLM

  • [ ] Realizar e interpretar la prueba t y la prueba F de la tabla ANOVA

  • [ ] Construir IC para \(\beta_j\), IC para \(E[Y|\mathbf{x}^*]\), IP para \(Y^*\)

  • [ ] Identificar violaciones de los supuestos LINE a partir de gráficos de residuos

  • [ ] Calcular e interpretar el VIF

Diagnósticos y Selección de Modelos#

  • [ ] Interpretar residuos vs ajustados, gráfico QQ, escala-ubicación, gráficos de apalancamiento

  • [ ] Identificar valores atípicos vs puntos de alto apalancamiento vs puntos influyentes

  • [ ] Comparar modelos usando AIC, BIC, \(R^2\) ajustado

  • [ ] Explicar el dilema sesgo-varianza para Ridge vs Lasso

Regresión Logística#

  • [ ] Derivar la fórmula de probabilidad de la regresión logística a partir del enlace logit

  • [ ] Interpretar log-momios, razones de momios y probabilidades

  • [ ] Evaluar el modelo con matriz de confusión: exactitud, sensibilidad, especificidad

  • [ ] Interpretar la curva ROC y el AUC

Regresión de Poisson y GLMs#

  • [ ] Enunciar las condiciones para la regresión de Poisson

  • [ ] Interpretar las razones de tasas (coeficientes exponenciados)

  • [ ] Diagnosticar sobredispersión: devianza residual / gl \(\gg 1\)

  • [ ] Identificar los tres componentes GLM para cualquier familia dada

  • [ ] Definir \(S(t)\), \(h(t)\), \(H(t)\) y enunciar sus relaciones

  • [ ] Explicar la censura por la derecha y por qué no puede ignorarse

  • [ ] Calcular un estimador simple de Kaplan-Meier a mano para un ejemplo pequeño

Consejos para la Preparación del Examen#

Recomendaciones generales:

  1. Trabaje la lista de verificación de diagnósticos antes de la sesión de repaso para que pueda identificar sus brechas pendientes.

  2. Practique la interpretación de resultados de modelos (tablas de coeficientes, tablas ANOVA, matrices de confusión) sin ejecutar código — el examen puede incluir salidas impresas.

  3. Preste especial atención a la interpretación de coeficientes: la respuesta siempre depende de la función de enlace y la escala de las covariables.

  4. Revise los supuestos de cada modelo y conozca al menos una herramienta de diagnóstico para verificar cada supuesto.

  5. Para la sección de GLMs, ser capaz de identificar la familia y la función de enlace correctas a partir de la descripción de un problema es esencial.

Horas de atención: Por favor, consulte la plataforma del curso (Bloque Neón / Sicua+) para conocer el horario de las horas de atención del repaso final. La Prof. Tabares realizará sesiones adicionales esta semana. Traiga preguntas o problemas específicos que desee trabajar.
